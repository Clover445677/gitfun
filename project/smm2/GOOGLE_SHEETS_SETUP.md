# Подключение Google Sheets

## 1. Подготовка в Google Cloud

1. Создайте проект в [Google Cloud Console](https://console.cloud.google.com/).
2. В разделе API включите **Google Sheets API**.
3. Создайте сервисный аккаунт и ключ в формате JSON.
4. Сохраните ключ как `credentials.json` в папке `smm2`.
   Вместо этого можно задать абсолютный путь к файлу через переменную окружения `GOOGLE_APPLICATION_CREDENTIALS`.
5. Откройте нужную Google таблицу и предоставьте сервисному аккаунту доступ **Редактор**.

Не добавляйте `credentials.json` в Git: файл содержит секретный ключ.

## 2. Установка зависимостей

```cmd
cd H:\gitfun\project\smm2
py -m pip install -r requirements.txt
```

## 3. Формат таблицы

Первая строка должна быть заголовком. Используются колонки:

| Дата | Тема | Рубрика | Описание поста | Идея/Доп. поле | Статус | Комментарий клиента |
| --- | --- | --- | --- | --- | --- | --- |

Поддерживаемые даты: `01.09`, `01.09.2026`, `01.09.26` или `2026-09-01`.
Для даты без года применяется текущий год.

## 4. Запуск и использование

Запустите сервер обычным способом:

```cmd
py -m uvicorn main:app --reload
```

В интерфейсе откройте **📅 Контент-план**, вставьте ссылку на Google Sheets и нажмите **Подключить таблицу**.
После импорта можно фильтровать посты, создавать ТЗ по одному, для всех записей или на ближайшие 30 дней. Все созданные ТЗ появляются в общей истории и поддерживают экспорт.
