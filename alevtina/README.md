# Алевтина — VPN и маршрутизация OpenAI

Инструменты для Windows и FlClashX: ChatGPT/OpenAI используют выбранный сервер США, а остальной трафик по умолчанию идёт напрямую.

| Компонент | Назначение |
| --- | --- |
| [ChatGPT Bridge](chatgpt-bridge/README.md) | Приложение с интерфейсом, управлением подключением и защитой маршрута |
| [VPN OpenAI](vpn-openai/README.md) | PowerShell-скрипт для настройки правил маршрутизации |

Начните с инструкции выбранного компонента: в ней описаны установка, требования, проверка подключения и откат настроек.

Для работы нужна собственная VPN-подписка в FlClashX. Для передачи приложения используйте чистый архив. Папка `ChatGPTBridge-data` содержит локальные настройки и резервные копии; её не следует передавать другим людям.
