# ChatGPT через США — 1.0.4

Надстройка для Windows 10/11 x64 и FlClashX. ChatGPT в обычном Google Chrome, приложение ChatGPT и Codex для Windows используют выбранный сервер США. Остальной интернет по умолчанию работает напрямую. Кнопка общего VPN проверяет серверы подписки и выбирает доступный сервер с наименьшей средней задержкой HTTPS-запросов; OpenAI остаётся на сервере США.

## Первый запуск, в том числе на другом ПК

1. Установите FlClashX, добавьте свою VPN-подписку и выберите активный профиль с сервером США.
2. Распакуйте чистый архив в доступную локальную папку, например C:\Users\ваше-имя\ChatGPTBridge. Запускайте EXE из распакованной папки. На проверенном компьютере запуск с диска H: приводил к отказу записи в настройки FlClashX; запуск из пользовательской папки на C: работает.
3. Откройте ChatGPTBridge.exe, нажмите «Настроить и подключить» и подтвердите запрос прав администратора. Для настройки нужна учётная запись Windows с правами администратора. Если программа уже имеет эти права, отдельный запрос может не появиться.
4. Дождитесь «ChatGPT подключён через США». После первой настройки перезапустите Chrome, чтобы он загрузил обязательное правило прокси. Затем используйте обычные вкладки и приложения.

На другом компьютере пути, профиль, имя сервера и резервная копия определяются заново. При нескольких серверах США программа попросит выбрать один в настройках. Рядом с EXE создаётся папка ChatGPTBridge-data.

Передавайте только чистый архив с EXE и этим README. Не передавайте ChatGPTBridge-data: резервные копии могут содержать URL подписки и другие личные настройки.

## Использование и защита от забывчивости

- Закрытие окна сворачивает приложение в трей. Маршрут продолжает работать. Повторное открытие — через значок US или ярлык на рабочем столе.
- Галочка «Запускать вместе с Windows» управляет автозапуском окна и моста. Отдельная задача защиты продолжает запускаться при входе в Windows: при выключенном автозапуске моста защищённые приложения блокируются до его ручного запуска.
- При недоступности США надстройка показывает предупреждение и ждёт восстановления. Прямого запасного маршрута и переключения OpenAI на другой сервер нет. Доступность проверяется примерно каждые 12 секунд.
- При полном выходе из надстройки обязательный прокси Chrome остаётся установленным, но становится недоступен. Фоновая защита блокирует обнаруженные нативные ChatGPT, Codex и VS Code, пока живой мост не подтвердит маршрут США.
- Фоновая задача проверяет настройки маршрута примерно раз в секунду. Изменённый режим или правила FlClashX включают дополнительную блокировку нативных приложений. Мост Chrome проверяет правила при каждом новом HTTPS-соединении.
- Переключайте общий VPN кнопкой надстройки. Остальные сайты используют выбранный по задержке сервер; при выключении возвращаются к DIRECT. OpenAI остаётся через США.

Защита нативных приложений использует брандмауэр Windows. Она запрещает их прямой выход через интерфейсы вне TUN FlClashX. При остановленном мосте или неподтверждённом маршруте блокируются и остальные сетевые функции VS Code. При исправном частичном VPN прочие запросы VS Code идут напрямую через ядро FlClashX, а запросы OpenAI — через США.

## Файлы и изменения на компьютере

Все собственные файлы надстройки, настройки, диагностика, каталог защищённых программ и резервные копии находятся в ChatGPTBridge-data рядом с EXE. Исполняемый файл не устанавливается в Program Files или ProgramData. После настройки не перемещайте папку: ярлык, автозапуск и задача защиты ссылаются на её текущий путь.

Программа изменяет существующие настройки FlClashX: включает TUN, локальный контроллер и режим «По правилам», добавляет постоянные правила активного профиля. Исходный YAML подписки не изменяется. Отдельный автозапуск FlClashX заменяется запуском надстройки.

Windows хранит собственные правила брандмауэра, пользовательскую задачу ChatGPTBridgeGuard-<SID> и значения автозапуска/политик Chrome. Задача работает под текущим пользователем с повышенными правами независимо от окна. Старые собственные файлы и служба предыдущих сборок удаляются при успешной установке новой защиты.

Для Chrome устанавливается обязательная локальная политика PAC: адреса OpenAI используют 127.0.0.1:18881, остальные адреса — DIRECT. QUIC и прямой UDP WebRTC отключаются. Chrome может показать «Управляется вашей организацией» из-за этих локальных настроек. Если обязательный прокси уже задан другим администратором, установка останавливается.

Мост передаёт HTTPS без расшифровки, не устанавливает сертификаты и не сохраняет переписку. В сетевых тестах записывается страна выхода без полного IP-адреса.

## Удаление настройки

Нажмите «Удалить настройку» и подтвердите запрос Windows. Собственные задача и правила брандмауэра удаляются, настройки Chrome, автозапуска и FlClashX восстанавливаются из первоначальной копии. Последующие изменения FlClashX могут быть заменены этой копией. EXE и личные резервные копии автоматически не удаляются.

## Проверки и пределы защиты

На текущем компьютере используется FlClashX 0.2.1 с сервером «🇺🇸 США». Реальные проверки охватывают установку защиты, запись рядом с EXE, запрос к ChatGPT с выходом loc=US, нативный процесс с брандмауэром, общий VPN и сохранение США для OpenAI, недоступность США, выключение TUN, закрытие моста, изменённый глобальный маршрут и восстановление. Отдельно проверяются атомарное сохранение, PAC, границы доменов и локальный HTTPS-мост. Подробные результаты — в verification исходного проекта; эта папка не входит в пользовательский архив.

Тесты вызывают реальные обработчики приложения; автоматическое нажатие кнопок в живом интерфейсе недоступно в этой среде. Перезагрузка Windows, снятие защиты на живой машине и второй компьютер с Windows 11 здесь не проверялись. Используется встроенный .NET Framework; Node.js для работы не нужен. [Сведения Microsoft о .NET Framework в Windows](https://learn.microsoft.com/en-us/dotnet/framework/install/on-windows-and-server).

Эта сборка не даёт абсолютной гарантии «ни одного запроса при любых обстоятельствах». Обнаружение изменения маршрута занимает время, новые исполняемые файлы обнаруживаются периодически. Все сторонние VPN, локальные прокси и расширения браузера не проверены. Codex внутри WSL, контейнера или удалённого компьютера и другие браузеры этой сборкой не защищаются. Изменение политик, выключение брандмауэра или удаление настройки снимает соответствующую защиту.

Название сервера не гарантирует географию IP. В выполненном тесте ChatGPT подтвердил US, но программа не проверяет страну при каждом запросе. Она управляет сетевым маршрутом и не скрывает историю аккаунта или другие признаки местоположения.

## Исходники и сборка

В исходном проекте запустите build.ps1 с параметром -OutputDirectory .\release. EXE поддерживает --self-test с путём к папке результатов; test-pac.js запускается через Node.js. Для обычной работы эти инструменты не нужны.

--integration-test, test-tun-loss.ps1 и test-forgotten-app.ps1 выполняют реальные сетевые проверки и временно изменяют текущую настройку. Они предназначены для разработки.
