# OpenAI через США, остальные сайты напрямую

Скрипт подготовлен для Windows и проверен на структуре настроек FlClashX 0.2.1.
Он решает проблему задержек у других сайтов разделением трафика. VPN остаётся
включённым; скрипт не отключает его по таймеру и не определяет окончание ответа.

## Установка

1. Запустите `Preview.cmd`: он покажет будущие правила без изменений.
2. Дождитесь окончания задач ChatGPT/Codex. Полностью выйдите из FlClashX через
   меню значка в трее — закрытие окна может только свернуть приложение.
3. Запустите `Apply.cmd`. Администратор для записи этих настроек не нужен.
4. Откройте FlClashX. Проверьте режим **«По правилам»**, включённый **TUN** и
   работающий VPN. Обновите вкладку ChatGPT и перезапустите ChatGPT/VS Code,
   чтобы старые соединения не сохраняли прежний маршрут.

Скрипт включает запуск FlClashX при входе в Windows и автоматический старт VPN
при запуске приложения. Проверьте после следующего входа: Windows или настройки
поставщика подписки могут ограничивать автозапуск. Скрипт не запускает FlClashX
сам и не изменяет текущие соединения.

По правилам:

- Домены OpenAI/ChatGPT, включая поддомены, направляются в единственный узел
  с названием «США»/USA/United States. Название выбирается из вашей подписки.
- Приложение ChatGPT, Codex и **весь VS Code** направляются туда же; это покрывает
  трафик расширений VS Code, но их загрузки также будут идти через VPN.
- Остальные сайты Chrome и остальные приложения используют прямое соединение.
- Локальная сеть и loopback остаются прямыми.

Локальные правила заменяют правила активного профиля и сохраняются отдельно
от файла подписки, поэтому обычное обновление серверов не должно их стереть.
В исходной подписке, URL, паролях и других профилях ничего не меняется.
Если другой сервис также требует VPN, его нужно добавить в правила.

У девушки нужно запустить эту же папку на её ПК: сервер выбирается из её
подписки. Передавайте только файлы из этой папки, **не резервные копии настроек**.
Резервная копия содержит приватные данные и остаётся рядом с настройками клиента.

## Проверка после установки

В FlClashX откройте список соединений (если скрыт — добавьте вкладку в настройках).
Отправьте сообщение в ChatGPT в Chrome, затем из приложения и Codex в VS Code.
Проверьте, что соответствующие соединения используют «США», а обычный сайт в
Chrome — `DIRECT`. Убедитесь отдельно, что выбранный узел действительно выдаёт
IP США: его название само по себе этого не доказывает.

Список доменов может измениться. Встроенный набор `GEOSITE,openai` используется,
если обнаружен в локальной GeoSite.dat; явные домены тоже включены. Дополнительные
сторонние службы, вход через внешнего провайдера, голос и новые функции могут
потребовать дополнительных правил. Это не универсальная гарантия маршрута каждого
запроса: проверьте все используемые функции в списке соединений.

**FlClashX должен работать.** При недоступности выбранного сервера правила не
переключаются на DIRECT, но при полном выключении/сбое клиента защита его правилами
пропадает. Системный запрет прямых соединений (Kill Switch) здесь не устанавливается.
Скрипт не скрывает историю входов и другие сведения аккаунта и не гарантирует,
что сервис не сможет определить страну по другим признакам.

## Откат и параметры

При применении выводится полный путь к резервной копии. Полностью закройте
FlClashX и выполните в PowerShell из этой папки, подставив этот путь:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Set-OpenAIRouting.ps1 -Action Restore -BackupPath 'C:\...\shared_preferences.json.openai-backup-....json'
```

После отката запустите клиент. Восстанавливается весь файл настроек на момент
резервного копирования, включая другие изменения, сделанные после установки.

Если серверов США несколько, укажите полное название узла, включая флаг:

```powershell
.\Set-OpenAIRouting.ps1 -Action Preview -ServerName '🇺🇸 США'
```

`-DomainsOnly` отключает правила по процессам, включая правило для всего VS Code.
Это уменьшает охват маршрутизации и требует проверки соединений Codex.
`-DataDir` позволяет указать другую папку настроек. По умолчанию действия
всегда только показывают изменения: для записи нужен `-Action Apply`.

Источники: [маршрутизация mihomo](https://wiki.metacubex.one/en/config/rules/),
[структура локальных правил FlClashX](https://github.com/pluralplay/FlClashX/blob/main/lib/models/profile.dart).
